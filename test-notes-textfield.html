🧪 Text-Notizen System Test

📝 Test-Anleitung

  1. Klicke auf den Button unten rechts oder drücke N
  2. Wähle Text-Modus mit T oder Button
  3. Der Cursor sollte sich zu ➕ ändern
  4. Klicke auf freie Stelle → Neue Notiz sollte erscheinen
  5. Klicke auf bestehende Notiz → Keine neue Notiz!
  6. Ziehe am Handle (≡) → Notiz verschieben
  7. Beim Ziehen: Keine neue Notiz erstellen!

✅ Was funktionieren sollte:

  • ✓ Klick auf Folie → Neue Notiz an Klick-Position
  • ✓ Cursor zeigt ➕ im Text-Modus
  • ✓ Cursor zeigt ✋ beim Handle
  • ✓ Ziehen verschiebt Notiz (keine neue Notiz!)
  • ✓ Klick auf Notiz → Editieren (keine neue Notiz!)

🐛 Zu prüfende Bugs:

  • ❌ Klick auf Notiz erstellt neue Notiz
  • ❌ Drag & Drop aus Notiz erstellt neue Notiz
  • ❌ Cursor ändert sich nicht
  • ❌ Klick auf freie Stelle funktioniert nicht
