# PDF Export - Quick Reference

## Quick Start

1. **Find the Export Button**  
   Look for the red "Export to PDF" button in the bottom-right corner

2. **Click to Export**  
   - Click the button to start export
   - Automatically uses 16:9 presentation format
   - System slides (first 2 + last) are excluded

3. **Save Your PDF**  
   - Wait for slides to load
   - Print dialog opens automatically
   - Choose "Save as PDF"
   - Set margins to "None"
   - Click Save

## What Gets Exported

✅ **Included:**
- All content slides
- High-contrast, clean styling (performance mode)
- 16:9 aspect ratio (1920px × 1080px)

❌ **Excluded:**
- First 2 slides (intro/menu slides)
- Last slide (system slide)
- Clock, buttons, and UI elements

## Keyboard Shortcuts

- **Open Print Dialog**: `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
- **Close Dropdown**: `Esc`

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Button not visible | Check if Font Awesome is loaded |
| Pop-up blocked | Allow pop-ups for this site |
| Wrong page size | Set paper size manually in print dialog |
| Auto-print not working | Press `Ctrl+P` / `Cmd+P` manually |

## Direct Link

You can also bookmark this URL for quick access:

```
https://your-presentation.com/?print-pdf&pdfFormat=16x9&excludeSlides=system
```

This will open the PDF export directly without clicking the button.

## Tips

✅ **DO**
- Preview before saving
- Use high-quality images
- Test both formats
- Enable background graphics

❌ **DON'T**
- Skip the preview
- Use low-resolution images
- Forget to set margins to "None"
- Disable background graphics
